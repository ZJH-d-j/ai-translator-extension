两分钟，装到你的浏览器

下载 ZIP 解压后用开发者模式加载，全程离线完成；上架商店后即可免开发者模式，敬请期待。

1

下载并解压

下载源码 ZIP，解压到本地任意目录。

2

打开扩展页

Edge 地址栏输入 edge://extensions，打开左侧「开发人员模式」。

3

加载扩展

点击「加载解压缩的扩展」，选择解压后的文件夹即可完成安装。

4

填入密钥

打开管理面板，填入 Base URL 与 API Key，测试连接通过即可使用。

你的 Key，你的数据

兼容任何 OpenAI 协议的服务商，密钥只保存在你自己的浏览器里。

任意兼容服务

DeepSeek、OpenAI、Azure、本地部署模型：只要支持 chat/completions 协议即可接入。

隐私本地优先

配置、历史记录与 Token 统计全部存储在本地浏览器，插件自身不持有任何服务器。

管理面板

语言方向切换、翻译历史回溯、Token 消耗统计，一切都在一个页面里完成。
